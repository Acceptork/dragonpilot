# 前車記憶解除審查

目前不能安全宣稱「前車離開後恢復」已解決。本輪未刪除記憶、未新增 timeout 自動解除，也未縮短跟車距離。

上一輪固定事實仍保留：事件窗 UNKNOWN 正向 target 限制累積約 63.95 秒，其中兩 lead 均未偵測約 23.89 秒；GOOD06 有約 10.6 秒連續限制。這些是指定事件窗統計，不等同本輪整路線開發集總量。

本輪另從完整可用原生 baseline 輸出建立 UNKNOWN episode 表，僅在同一分割、時間連續時合併。私有檔 `LEAD_EPISODES.private.json` 保留 episode 起訖、無 lead 時間、正 target 被壓成非正值的時間、可用 radar ID 與結束後 lead 訊號。`CACHE_DIAGNOSIS.json` 保存彙總。

| 類別 | 現有訊號能否可靠確認 | 處置 |
|---|---|---|
| A：短暫 dropout、同一前車回來 | 幾何與相對速度可支持，但不能單靠相似數字證明同一物體 | 保留保守限制 |
| B：可靠離開 ego path | 無 lead 不等於道路無障礙；缺少可驗證的物體延續與離開標記 | 不自動解除 |
| C：新 lead 接管 | 新的偵測可觀察，但 raw lead index 不代表 identity | 不將其當成舊 lead 已安全離開 |
| D：無法判斷 | 本輪 episode 均未取得足夠物體身分真值 | 不授予積極 recovery |

H3「UNKNOWN 限制確實造成恢復延遲」有控制鏈證據；「這些限制都不必要」沒有證據。整段 UNKNOWN 時間與真正削掉正 target 的時間分開統計，不能把前者全部當成可回收延遲。

受限恢復也需要證明前方空間安全，不能只因兩個 lead 都消失很久就允許加速。缺少可靠 object identity 已符合本輪停止條件。下一次應收集正常前車轉出／換道離開、短暫遮擋後重現，以及自然發生的新前車接管，並同步人工標記同一物體延續；不可故意製造危險 cut-in。

依修正後分割有 3 段連續UNKNOWN觀測，合計約 157.08 秒；其中真正壓低正target約 38.79 秒，兩lead都未偵測約 104.70 秒。三者不能互相替代。它們的有效radarTrackId沒有提供可靠物體identity；本輪均保留D類。
