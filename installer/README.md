# comma 3 installer for my-crv

On the comma 3 initial setup screen, choose Custom Software and enter this exact URL:

```text
https://raw.githubusercontent.com/Acceptork/dragonpilot/installer-my-crv/installer/installer
```

The file is an ARM64 ELF executable, the format required by the comma AGNOS setup screen. It uses comma's installer to clone `https://github.com/Acceptork/dragonpilot.git` with branch `my-crv` into `/data/openpilot`. The source branch remains separate from this installer branch; future installs clone the latest `my-crv` HEAD.

The binary is generated by [the build workflow](../.github/workflows/build-my-crv-installer.yml). That workflow downloads the comma installer ELF, checks its format and reserved placeholders, substitutes the repository and branch, publishes this file, and reads the raw GitHub URL back with an AGNOS-style user agent to verify the exact bytes. Do not replace this file with a shell script or manifest; setup requires the ELF magic bytes.

## Failure behavior

The setup screen reports download and invalid-format errors. The upstream comma installer uses a hard assertion when `git clone` fails; it does not render a detailed clone error in the install UI. This binary inherits that behavior. A detailed clone-failure screen would require a custom rebuilt installer and device testing.

No GitHub Pages or custom domain is needed. This was verified by the build workflow as an HTTP download; the installer has not been run on physical comma 3 hardware.
